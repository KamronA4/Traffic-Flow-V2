# Village MVP Demo Script
## Professional Municipal Traffic Planning Platform

### 🎯 **Demo Overview** (30-45 minutes)
This demo showcases Village as a comprehensive municipal traffic planning platform with advanced analytics, AI integration, and professional-grade reporting capabilities.

---

## 🚀 **Opening Hook** (2 minutes)

> "Imagine you're the Transportation Director for Providence, Rhode Island. It's Monday morning, and you need to:
> - Brief the Mayor on weekend traffic incidents
> - Analyze whether the new I-95 construction is working
> - Predict next month's problem areas
> - Generate a board presentation for Thursday
> 
> Traditional tools would take you all week. With Village, you can do this in 30 minutes."

**Launch Application:**
```bash
streamlit run code/main.py
```

## 📊 **Module 1: Live Traffic Monitoring** (8 minutes)

### Scenario: "Monday Morning Traffic Briefing"

**Navigate to: 🚦 Live Traffic**

1. **Real-time Dashboard Overview** (2 min)
   - Point out the professional interface design
   - Highlight auto-refresh capability (15-minute intervals)
   - Show system status indicators in sidebar

2. **Interactive Filtering** (2 min)
   - Demonstrate date/time filtering
   - Show how planners can focus on specific incidents
   - Filter to current date and rush hour (7-9 AM)

3. **Map Intelligence** (3 min)
   - **Click on incident markers** to show AI-powered analysis
   - Demonstrate real-time context cards with:
     - Current situation analysis
     - Municipal planning insights
     - Related news articles and citations
   - Show different severity color coding

4. **Export Capabilities** (1 min)
   - Download incident data as CSV
   - Show how this integrates into planning workflows

**Key Demo Points:**
- "Notice how clicking any incident immediately provides AI-powered context"
- "The system automatically finds related news articles and planning considerations"
- "Color coding helps prioritize response efforts"

## 📈 **Module 2: Advanced Analytics** (12 minutes)

### Scenario: "Data-Driven Planning Decisions"

**Navigate to: 📈 Analytics**

1. **Descriptive Statistics** (3 min)
   - Show comprehensive statistical dashboard
   - Demonstrate interactive correlation matrix
   - Highlight distribution analysis with Plotly charts
   - **Key insight**: "See how incident severity correlates with duration"

2. **Statistical Hypothesis Testing** (4 min)
   - **ANOVA Analysis**: "Let's test if incident duration differs by location"
   - Show live calculation with F-statistic and p-values
   - Demonstrate T-test for rush hour vs non-rush hour
   - **Academic rigor**: "All tests include proper statistical validation"

3. **Predictive Modeling** (3 min)
   - Select "Random Forest" model
   - Choose features: hour, location, weather conditions
   - **Live model training** with performance metrics
   - Show feature importance analysis
   - **Key insight**: "Hour of day is the strongest predictor"

4. **Bias Detection** (2 min)
   - Demonstrate geographical bias analysis
   - Show temporal bias testing
   - Highlight data quality metrics
   - **Academic value**: "Built-in algorithmic fairness testing"

**Key Demo Points:**
- "This isn't just charts - it's rigorous statistical analysis"
- "Every test includes methodology and reproducible results"
- "Bias detection ensures equitable resource allocation"
