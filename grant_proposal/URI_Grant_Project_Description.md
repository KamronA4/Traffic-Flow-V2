# URI Undergraduate Research Grant Proposal

**Project Title:** Village: AI-Powered Municipal Traffic Planning Platform for Rhode Island Communities  
**Student Name:** Kamron Aggor  
**Project Start Date:** March 1, 2025  
**Project End Date:** August 31, 2025  
**Amount of Funding Requested:** $1,000

## Project Description

### Goal

The overall goal of this project is to develop and pilot an innovative web-based platform called "Village" that empowers Rhode Island municipalities to make data-driven traffic planning decisions using real-time traffic data, artificial intelligence analysis, and predictive modeling. This platform will transform how small and medium-sized municipalities approach traffic management by providing them with enterprise-level tools typically only available to major cities, ultimately improving road safety, reducing congestion, and enhancing quality of life for Rhode Island residents.

### Project Objectives

This project aims to achieve the following specific objectives:

1. **Complete Advanced Feature Development**: Finalize the implementation of predictive analytics algorithms that can forecast traffic patterns based on historical data, weather conditions, and special events. Additionally, develop 3D visualization capabilities that allow planners to view traffic flow in an intuitive, spatial format.

2. **Conduct Municipal Pilot Program**: Partner with 2-3 Rhode Island municipalities (targeting Providence, Warwick, and Newport) to deploy the platform in real-world settings, training municipal staff and collecting usage data.

3. **Measure Impact and Effectiveness**: Quantitatively assess how the platform improves traffic planning efficiency by tracking metrics such as time-to-decision, accuracy of traffic predictions, and user satisfaction scores.

4. **Iterate Based on User Feedback**: Conduct structured interviews and surveys with municipal users to identify pain points and improvement opportunities, then implement these enhancements.

5. **Prepare for Commercialization**: Develop a sustainable business model and prepare the platform for wider deployment across Rhode Island and eventually nationwide.

### Project Plan

The project will unfold over six months according to the following timeline:

**Months 1-2 (March-April 2025): Feature Development Phase**
- Week 1-4: Implement machine learning algorithms for traffic pattern prediction using TensorFlow and historical traffic data
- Week 5-6: Develop 3D visualization module using Three.js and integrate with existing mapping infrastructure
- Week 7-8: Create comprehensive testing suite and conduct quality assurance testing

**Month 3 (May 2025): Municipal Recruitment and Training**
- Week 9-10: Present platform to municipal planning departments and secure pilot partnerships
- Week 11-12: Develop training materials and conduct hands-on workshops with municipal staff

**Months 4-5 (June-July 2025): Pilot Implementation**
- Week 13-16: Deploy platform in pilot municipalities with daily monitoring
- Week 17-20: Collect usage analytics, conduct bi-weekly check-ins with users, and provide technical support

**Month 6 (August 2025): Analysis and Iteration**
- Week 21-22: Analyze collected data and conduct formal user interviews
- Week 23-24: Implement priority improvements and prepare final report/presentation

### Your Contribution to the Project Concept

This project represents my original vision and work, conceived from personal observations of traffic inefficiencies in Rhode Island communities and conversations with local officials about their resource constraints. My specific contributions include:

1. **Conceptualization**: I identified the gap between available traffic planning tools and municipal needs through interviews with town planners in Warwick and Cranston.

2. **Full-Stack Development**: I architected and developed the entire platform using Python (Streamlit), integrating multiple APIs (TomTom for traffic data, Perplexity AI for analysis) and creating a responsive user interface.

3. **AI Integration Design**: I designed the system for incorporating large language models to provide context-aware traffic analysis, making complex data accessible to non-technical users.

4. **Database Architecture**: I created a scalable database schema that efficiently stores and retrieves millions of traffic incident records while maintaining sub-second query performance.

5. **Business Model Development**: I researched and developed a tiered subscription model that makes the platform accessible to municipalities of all sizes.
