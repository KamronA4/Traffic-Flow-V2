# URI Undergraduate Research Grant Submission Checklist

## Pre-Submission Requirements

### ✅ Documents to Prepare
- [ ] Project Description (2-3 pages)
  - [ ] Proper heading with all required information
  - [ ] All sections addressed (Goal, Objectives, Plan, etc.)
  - [ ] References properly formatted
  - [ ] IRB statement included
  - [ ] Proofread for grammar and clarity

- [ ] Faculty Mentor Support Letter
  - [ ] Confirms your original contribution
  - [ ] Describes mentor's role
  - [ ] On official letterhead (if possible)
  - [ ] Signed and dated

- [ ] Budget Worksheet
  - [ ] Uses provided template
  - [ ] All items justified
  - [ ] Totals correctly to $1,000 or under
  - [ ] No ineligible expenses included

- [ ] Budget Explanation
  - [ ] Separate page from worksheet
  - [ ] Clear justification for each item
  - [ ] Explains how funds support project goals

### ✅ Technical Requirements
- [ ] InfoReady Review account created
- [ ] All documents in PDF format
- [ ] File names clearly identify contents
- [ ] Combined file size under system limit

## Timeline Management

## Quality Checks

### Project Description
- [ ] Answers all required questions completely
- [ ] Written for general audience (avoid jargon)
- [ ] Shows clear timeline with specific milestones
- [ ] Emphasizes YOUR original contribution
- [ ] Includes measurable outcomes
- [ ] Demonstrates benefit to others

### Budget
- [ ] Every item directly supports project goals
- [ ] No vague categories ("miscellaneous supplies")
- [ ] Reasonable costs (research typical prices)
- [ ] Travel includes department match mention
- [ ] Equipment reverting to department noted

### Overall Application
- [ ] Consistent project title throughout
- [ ] Dates are logical and realistic
- [ ] No conflicts with academic calendar
- [ ] Professional tone throughout
- [ ] Clear how URI benefits

## Common Mistakes to Avoid

❌ **Don't:**
- Submit a project that's just helping faculty research
- Request funds for work already completed
- Include salary or personal expenses
- Forget to explain technical terms
- Submit at the last minute
- Assume reviewers know your field

✅ **Do:**
- Emphasize innovation and impact
- Show clear personal growth goals
- Connect to broader applications
- Include specific, measurable outcomes
- Submit early for technical issues
- Have others review your application

## Post-Submission

### If Awarded:
1. Send thank you note to selection committee
2. Update faculty mentor immediately
3. Create project timeline with milestones
4. Set up accounting for grant funds
5. Begin IRB application if needed

### If Not Awarded:
1. Request feedback from committee
2. Thank faculty mentor for support
3. Consider other funding sources
4. Revise proposal for next cycle
5. Continue project if possible

## Alternative Funding to Consider

If URI grant doesn't work out:
- URI Foundation grants
- Department-specific funding
- External competitions (hackathons with prizes)
- Corporate sponsorship (local tech companies)
- Crowdfunding for civic tech projects
- Municipal partnerships/pilots
